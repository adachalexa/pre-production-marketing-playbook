# The Pre-Production Marketing Playbook

A choose-your-path website comparing how six films were marketed before and after release, built from the SMACC Fall 2026 semester research.

- **Blockbusters:** The Odyssey, Barbie, Sinners
- **Small budget:** Obsession, Anyone But You, Backrooms

Each film page breaks the research into eight questions: Did it work? How was it received? What was made? Who was in it and who they reached? How was it sold? Who showed up? What did people say online? Did it last?

## Site map

| Download the deck and paper | `download.html` |

## Run it

It is a static site with no build step. Open `index.html` in a browser, or publish with GitHub Pages (Settings → Pages → deploy from the `main` branch, root folder).
